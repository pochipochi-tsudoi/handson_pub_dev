## ハンズオンのゴール（到達点）

1) Flutterの基礎を学ぶ
- 画面構成（Scaffold / AppBar / ListView / TextField など）
- 非同期（Future / async-await）の触り

2) APIのGETを理解する
- HTTP GETでデータを取得する流れ
- ステータスコードと例外処理の基本
- JSON → Dartモデルへの変換

3) ファイル分割（責務分離）を学ぶ
- UI（View）とロジック（State）と通信（Repository/DataSource）を分離
- 「どこに何を書くべきか」の型を持ち帰る

4) Freezed / Riverpod の初歩
- Freezedで immutable なモデル / sealed class（状態）を作る
- Riverpodで状態管理（検索クエリ、取得中、結果、エラー）を扱う
- Providerの基本的な使い方（ref.watch / ref.read）

## 作成するアプリ（必須要件）

### アプリ概要

pub.dev のパッケージを検索できるアプリ

最低限の画面
- 検索画面（Search）
- 検索バー（TextField）
- 検索ボタン or 入力で検索（どちらでもOK）
- 検索結果一覧（ListView）◊
- ローディング表示
- エラー表示（通信失敗など）
- 詳細は「まずはリスト表示まで」を必須にすると進行が安定します

API（GET）
- pub.dev の検索APIを叩いて結果を表示
- 取得したJSONをモデルに変換してUIに出す
状態設計（Riverpod + Freezedの題材にちょうど良い）

検索状態を sealed class にすると学びが強いです。
- Idle（初期）
- Loading
- Success(results)
- Error(message)

検索クエリは
- TextEditingControllerで保持（UI）
- or Providerで保持（発展）
どちらでもOK。ハンズオンならまずControllerで十分。

⸻
